# M Zeeshan — Portfolio

Simple static HTML / CSS / JS site. No npm, no build step.

## Open locally

Double-click `index.html`, or open the folder in any static host / Live Server.

## Files

- `index.html` — full site
- `assets/css/styles.css` — styles
- `assets/js/app.js` — interactions + content config
- `assets/img/` — photos and project screenshots

## Customize

1. Edit links in `CONFIG` at the top of `assets/js/app.js`
2. Replace projects / copy in `index.html`
3. Add `assets/resume.pdf` for the resume buttons
